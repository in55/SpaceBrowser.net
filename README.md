# 空间浏览器 SpaceBrowser.net

> 仓储空间智能体 — 把仓库装进浏览器，让每一件商品都有「门牌号」。
> 智能体大脑基于极智平台（LLM · Workflow · 知识库 · MCP）构建，本仓库为空间呈现层源码。

## 功能

- 首屏可交互 3D 数字孪生仓库（鼠标拖拽环视 / 滚轮缩放）
- 对话式找货定位：一句话 → 3D 镜头逐级飞行 → 层位特写
- 智能上架推荐：ABC 周转分层 + 黄金高度规则 + 巷道均衡
- 找货路径优化：波次合并 + S 型遍历 + 3D 路径动画
- 盘点定位与差异闭环：一扫三用（核销 + 定位 + 进度），自动重盘工单

## 运行

纯 HTML + CSS + JS，零构建零依赖：

```
直接双击 index.html 即可（Three.js 已本地化于 inc/）
```

## 结构

```
index.html        主页面（单文件内嵌样式与逻辑）
inc/three.min.js  Three.js r160 本地副本
```
